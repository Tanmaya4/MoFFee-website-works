# MoFFee Website Color Palette

## Primary Colors

### Primary
- **Light Mode**: `hsl(32, 80%, 45%)` - Golden/Orange accent color
- **Dark Mode**: `hsl(40, 85%, 50%)` - Brighter gold
- **Usage**: Main brand color, buttons, highlights, "Benefits" and "Five-Sense" text
- **Tailwind Class**: `text-primary`, `bg-primary`

### Primary Foreground
- **Light Mode**: `hsl(30, 25%, 97%)` - Off-white
- **Dark Mode**: `hsl(20, 15%, 8%)` - Very dark charcoal
- **Usage**: Text on primary backgrounds
- **Tailwind Class**: `text-primary-foreground`

## Color Usage Guidelines

### Consistent Highlighting
- Use `text-primary` for highlighted text in headings (e.g., "Benefits", "Five-Sense")
- Use `text-gold` for premium branding elements
- Use `text-gold-light` for subtle gold accents

### Backgrounds
- Use `bg-charcoal` for dark sections with white text
- Use `bg-cream` for light, warm sections
- Use `bg-background` for main page background

### Text Hierarchy
- Primary text: `text-foreground`
- Secondary text: `text-muted-foreground`
- Accent text: `text-primary` or `text-gold`
